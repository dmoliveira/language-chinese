# Tech Study Vocabulary Basics

## Key words

- 电脑 — computer
- 软件 — software
- 代码 — code
- 程序 — program
- 人工智能 — artificial intelligence
- 学习 — study / learn

## Example

- 我学习人工智能。— I study artificial intelligence.
