# Starter Vocabulary Reference

## What This Reference Is For

Use this page to review the most useful words from the first beginner lessons.

## Core Starter Words

- 你好 — nǐ hǎo — hello
- 我 — wǒ — I, me
- 你 — nǐ — you
- 好 — hǎo — good
- 叫 — jiào — to be called
- 名字 — míngzi — name
- 很 — hěn — very
- 高兴 — gāoxìng — happy, glad
- 认识 — rènshi — to know / meet

## Useful Beginner Chunks

- 我叫 ... — my name is ...
- 你呢？— and you?
- 很高兴认识你 — nice to meet you

## How To Study This Vocabulary

- learn the sound first
- connect hanzi and pinyin second
- use the word inside a short sentence third

## Examples

- 我叫 Lin。
- 你叫什么名字？
- 很高兴认识你。

## Common Mistakes

- Memorizing isolated words without using them in phrases.
- Forgetting tone marks in pinyin study.
- Trying to learn too many words before the first set feels automatic.
