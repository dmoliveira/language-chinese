# Beginner Milestone Checklist

## Purpose

Use this checklist at the end of the first foundation slice to see what you can already do and what you should review next.

## Instructions

Mark each statement as **done**, **almost**, or **not yet**.

## Questions or Tasks

- I can greet someone with **你好**.
- I can say **我叫 ...** and add my own name.
- I can understand the main meaning of a short greeting dialogue.
- I can recognize a few core characters such as **我**, **你**, and **好**.
- I can write a one-line self-introduction.
- I can use beginner references to review pinyin and pronunciation.

## Scoring or Interpretation Guidance

- Mostly **done**: move to the next beginner slice.
- Mixed **done** and **almost**: repeat speaking and reading once more.
- Mostly **not yet**: restart with the two-week starter plan.

## Recommended Next Steps

- If strong: repeat the current lessons at normal speed and prepare for the next beginner content slice
- If mixed: repeat decks and references
- If weak: restart with `study-plan-foundations-001`
