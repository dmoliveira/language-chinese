# Write a Simple Plan

## Objectives

- write short place and plan sentences
- use basic time and movement language

## Pattern Support

- 我明天去学校。— I am going to school tomorrow.
- 下午我在图书馆。— In the afternoon I am at the library.

## How To Build The Plan

1. choose a time word
2. add a movement verb such as 去
3. name the place
4. optional: add a second sentence with 在 + place

## Practice

1. Write one sentence with 明天.
2. Write one sentence with 去.
3. Write one sentence with 在 + place.
4. Combine them into a 2- to 3-line mini plan.
5. Read your plan aloud after writing it.

## Answer Key or Rubric

Possible model:

- 我明天去学校。
- 下午我在图书馆。

Rubric:

- includes a time word
- includes a place
- includes a movement or location pattern
