# Contributing

Thank you for helping improve this project.

## Before contributing

Please keep contributions:

- accessible
- legally safe
- beginner-friendly
- clear and respectful
- appropriately scoped

## Contribution types

You can contribute:

- code and site improvements
- lessons and references
- study plans and flashcards
- accessibility improvements
- source manifests and attribution cleanup
- documentation and contributor workflow improvements

## Licensing expectations

By contributing, you confirm that:

- you wrote the submitted material, or
- you have the right to contribute it under compatible terms

Repository licensing model:

- code: MIT
- original educational content: CC BY-SA 4.0

## Content rules

When contributing learning content:

- use the templates under `content/templates/`
- include complete metadata
- include answer keys or rubrics where required
- include transcripts for audio-based material
- keep English explanations concise and clear
- avoid overclaiming AI scoring accuracy

## Third-party material rules

- record source, license, and attribution for any reused asset
- do not add unclear-license materials
- prefer link-only references when redistribution rights are uncertain

## Quality expectations

Contributions should aim to preserve:

- accessibility baseline
- consistent learner level labeling
- professional public presentation
- accurate cross-links between lessons, references, decks, and evaluations

## Suggested workflow

1. review existing specs under `docs/specs/`
2. keep changes focused
3. update related docs/content when needed
4. run relevant validation for touched areas

## Good first contribution areas

- improve public site copy
- add missing reference pages
- expand flashcard/export support
- improve lesson linking and navigation
- strengthen accessibility and mobile presentation
