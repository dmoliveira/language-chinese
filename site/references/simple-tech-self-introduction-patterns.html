Simple Tech Self-Introduction Patterns

Beginner patterns for saying what you study or work on in software and AI-related contexts.

Useful patterns

  • 我学习人工智能。 — I study artificial intelligence.
  • 我写代码。 — I write code.
  • 我喜欢软件开发。 — I like software development.

How to use these patterns

  • start with one study/work sentence
  • add one action sentence
  • optional: add one interest sentence

Mini examples

我学习人工智能，也写代码。
wǒ xuéxí réngōng zhìnéng, yě xiě dàimǎ.
I study artificial intelligence and also write code.

Study tip

Use your real interests if possible. The more personally true the sentence is, the easier it is to remember.
