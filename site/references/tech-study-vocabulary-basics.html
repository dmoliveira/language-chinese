Tech Study Vocabulary Basics

A beginner-friendly set of Chinese words for coding, software, and AI-related learning contexts.

Key words

  • 电脑 — computer
  • 软件 — software
  • 代码 — code
  • 程序 — program
  • 人工智能 — artificial intelligence
  • 学习 — study / learn

Example

我学习人工智能。
wǒ xuéxí réngōng zhìnéng.
I study artificial intelligence.
