Core Sentence Pattern Basics

A beginner-friendly guide to the first sentence patterns used across the starter lessons.

What this reference is for

Use this page to understand the first sentence shapes that appear again and again in beginner Chinese.

Starter patterns

  • 你好 — hello
  • 我叫 + name — my name is ...
  • 你呢？— and you?
  • 很高兴认识你 — nice to meet you

Pattern breakdown

我叫 Anna。
wǒ jiào Anna.
My name is Anna.
你叫什么名字？
nǐ jiào shénme míngzi?
What is your name?

Common mistakes

  • Putting the name before 我叫.
  • Trying to make the sentence too long too early.
  • Translating word by word from English.
