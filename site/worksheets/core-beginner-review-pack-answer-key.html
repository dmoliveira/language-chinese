Core Beginner Review Pack — Answer Key

Suggested answers for the Level 1 core beginner review pack.

Routine Review

Accept any 3 understandable daily routine lines using time words and routine verbs such as 早上 / 晚上 / 起床 / 学习.

Food & Preferences Review

Accept one sentence each with 喜欢, 想, and 要, plus a yes/no question using 吗, for example: 我喜欢茶。 我想喝咖啡。 我要米饭。 你喜欢茶吗？

Family Review

Accept 3 short lines introducing a family member and one work/study detail, for example: 这是我姐姐。 她是学生。 她学习中文。

Places & Plans Review

Accept a short plan such as: 我明天去学校。 下午我在图书馆。
