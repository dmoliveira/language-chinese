Foundations Review Pack

A print-friendly pack for reviewing the Level 0 foundation material.

Pronunciation Review

  • Write 3 examples for first, second, third, and fourth tones.
  • Read aloud: 你好 / 我叫 / 很高兴认识你
  • Mark which syllables feel hardest and repeat them 5 times.

Reading Review

  • Match 我 / 你 / 好 / 叫 / 名字 to meaning.
  • Underline the self-introduction sentence in a short text.
  • Write one line using 我叫 + your name.

Writing Review

  • Copy the model sentence once.
  • Rewrite it from memory.
  • Add a second polite sentence if ready.

Self-check Prompt

Can you greet someone, say your name, read a tiny text, and write one short self-introduction line without looking at the model too much?
