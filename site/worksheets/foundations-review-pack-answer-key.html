Foundations Review Pack — Answer Key

Suggested answers for the Level 0 foundations review pack.

Pronunciation Review

Accept any accurate tone examples. Learners should produce clearly differentiated tone patterns and pronounce 你好 / 我叫 / 很高兴认识你 with stable chunks.

Reading Review

  • 我 = I / me
  • 你 = you
  • 好 = good
  • 叫 = to be called
  • 名字 = name
  • Example answer: 我叫 Alex。

Writing Review

  • Model sentence may vary by name.
  • Accept: 你好，我叫 Emma。
  • Optional second sentence: 很高兴认识你。
