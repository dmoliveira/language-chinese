Build Simple Self-Introduction Sentences

Write a few short beginner sentences to introduce yourself in Chinese.

Objectives

  • Write a basic self-introduction pattern.
  • Use 我叫 ... correctly.
  • Combine greeting and name in a short response.

Vocabulary and Patterns

  • 你好 — nǐ hǎo — hello
  • 我叫 ... — wǒ jiào ... — my name is ...
  • 很高兴认识你 — hěn gāoxìng rènshi nǐ — nice to meet you

Core pattern: 你好，我叫 + name。

Expansion pattern: 你好，我叫 + name。很高兴认识你。

Lesson Content

你好，我叫 Emma。
nǐ hǎo, wǒ jiào Emma.
Hello, my name is Emma.
你好，我叫 Emma。很高兴认识你。
nǐ hǎo, wǒ jiào Emma. hěn gāoxìng rènshi nǐ.
Hello, my name is Emma. Nice to meet you.

Writing process

  • copy the model once
  • replace the name
  • read your sentence aloud
  • add one polite ending if ready

Practice

  1. Write: “Hello, my name is Alex.”
  2. Replace the name in this sentence: 你好，我叫 ___。
  3. Write a two-sentence self-introduction using 你好 and 很高兴认识你.
  4. Write the short model once from memory.
  5. Write one version with your real name and one with an example name.

Answer Key or Rubric

Possible answers

  1. 你好，我叫 Alex。
  2. Any personal or example name is acceptable.
  3. Example: 你好，我叫 Maria。很高兴认识你。
  4. Any accurate reconstruction of the model is acceptable.
  5. Both versions are acceptable if the sentence order is correct.

Rubric

  • Uses greeting correctly.
  • Uses 我叫 in correct position.
  • Produces a clear, short introduction.

Before You Write

  • Say the pattern aloud before writing.
  • Notice the order: greeting → 我叫 → name.
  • Stability is more important than complexity.

Guided Build

  1. Write 你好
  2. Add 我叫
  3. Add your name
  4. Optional: add 很高兴认识你
