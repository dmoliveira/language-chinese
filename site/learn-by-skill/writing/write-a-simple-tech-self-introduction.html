Write a Simple Tech Self-Introduction

Write a few short sentences about what you study or work on in tech.

Objectives

  • write a short intro about your tech interests
  • use simple self-introduction and study/work patterns

Pattern support

我学习人工智能。
wǒ xuéxí réngōng zhìnéng.
I study artificial intelligence.
我写代码。
wǒ xiě dàimǎ.
I write code.
我喜欢软件开发。
wǒ xǐhuan ruǎnjiàn kāifā.
I like software development.

How to build the intro

  1. say what you study or work on
  2. add one action such as 写代码
  3. add one interest if you want

Practice

  1. Write one sentence about what you study.
  2. Write one sentence about what you do.
  3. Write one sentence about what you like.
  4. Combine them into a short tech self-introduction.

Answer Key or Rubric

Possible model

  • 我学习人工智能。
  • 我写代码。
  • 我喜欢软件开发。

Rubric

  • includes at least two tech words
  • stays clear and beginner-friendly
  • communicates one real study/work focus
