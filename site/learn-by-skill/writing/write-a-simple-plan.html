Level 1 writing

Write a Simple Plan

Write a few short sentences about where you will go and when.

Objectives

  • write short place and plan sentences
  • use basic time and movement language

Pattern support

我明天去学校。
wǒ míngtiān qù xuéxiào.
I am going to school tomorrow.
下午我在图书馆。
xiàwǔ wǒ zài túshūguǎn.
In the afternoon I am at the library.

How to build the plan

  1. choose a time word
  2. add a movement verb such as 去
  3. name the place
  4. optional: add a second sentence with 在 + place

Practice

  1. Write one sentence with 明天.
  2. Write one sentence with 去.
  3. Write one sentence with 在 + place.
  4. Combine them into a 2- to 3-line mini plan.
  5. Read your plan aloud after writing it.

Answer Key or Rubric

Possible model

  • 我明天去学校。
  • 下午我在图书馆。

Rubric

  • includes a time word
  • includes a place
  • includes a movement or location pattern

Related references

  • Place Words and Location Basics
  • Basic Plan and Time Expressions

Writing tip

Write the time first, then the movement, then the place. This keeps the sentence stable.
