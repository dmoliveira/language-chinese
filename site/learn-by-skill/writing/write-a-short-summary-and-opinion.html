Level 3 writing

Write a Short Summary and Opinion

Write a short summary of a topic and add one simple opinion.

Objectives

  • write a short summary
  • add one simple response or opinion

Pattern support

这篇文章说学习中文的方法。
zhè piān wénzhāng shuō xuéxí zhōngwén de fāngfǎ.
This text talks about ways to study Chinese.
我觉得这个方法很好。
wǒ juéde zhège fāngfǎ hěn hǎo.
I think this method is very good.

How to build the response

  1. state the topic
  2. give one support detail
  3. add one short opinion

Practice

  1. Write one summary sentence.
  2. Write one supporting detail.
  3. Write one opinion sentence.
  4. Combine them into a 2- to 3-line response.

Answer Key or Rubric

Possible model

  • 这篇文章说学习中文的方法。
  • 要常常复习。
  • 我觉得这个方法很好。

Rubric

  • includes the topic
  • includes one support point
  • adds one short opinion clearly
