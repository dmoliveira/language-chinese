Level 2 writing

Write About Your Habits and Preferences

Write a short paragraph about what you usually do and what you prefer.

Objectives

  • write a short connected paragraph
  • include one habit and one preference

Pattern support

我每天喝茶。
wǒ měitiān hē chá.
I drink tea every day.
我更喜欢茶。
wǒ gèng xǐhuan chá.
I prefer tea more.

How to build the paragraph

  1. write one habit sentence
  2. write one preference sentence
  3. optionally compare two choices
  4. read the paragraph aloud

Practice

  1. Write one sentence using 每天 or 常常.
  2. Write one sentence using 喜欢.
  3. Write one sentence with 更 or 比 if ready.
  4. Combine them into a 3-line mini paragraph.

Answer Key or Rubric

Possible model

  • 我每天喝茶。
  • 我常常看书。
  • 我更喜欢茶。

Rubric

  • includes one habit line
  • includes one preference line
  • stays clear and short
