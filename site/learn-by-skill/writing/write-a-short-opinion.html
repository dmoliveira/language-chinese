Level 2 writing

Write a Short Opinion

Write a short connected opinion with one supporting detail.

Objectives

  • write a short opinion line
  • add one supporting detail or reason

Pattern support

我觉得这个很好。
wǒ juéde zhège hěn hǎo.
I think this is very good.
因为很方便。
yīnwèi hěn fāngbiàn.
Because it is convenient.

How to build the opinion

  1. state what you think
  2. add one simple reason
  3. keep the sentence short and clear

Practice

  1. Write one opinion sentence using 觉得.
  2. Add one reason with 因为.
  3. Write a 2-line opinion note.
  4. Read it aloud after writing.

Answer Key or Rubric

Possible model

  • 我觉得这个很好。
  • 因为很方便。

Rubric

  • includes one opinion phrase
  • includes one supporting detail
  • stays understandable and short
