Tech Study Introduction Listening

Listen to a short introduction about studying coding, software, or AI.

Objectives

  • understand a short tech-related self-introduction
  • recognize a few software/AI study words

Before you listen

  • Listen for the field first: software, code, or AI.
  • Then listen for the action: study, write, or like.
  • Finally listen for one personal detail.

Vocabulary focus

  • 电脑 — computer
  • 软件 — software
  • 代码 — code
  • 程序 — program
  • 人工智能 — artificial intelligence
  • 学习 — study

Sample listening lines

我学习人工智能。
wǒ xuéxí réngōng zhìnéng.
I study artificial intelligence.
我写代码。
wǒ xiě dàimǎ.
I write code.
我喜欢软件开发。
wǒ xǐhuan ruǎnjiàn kāifā.
I like software development.

Practice

  1. Which field does the speaker study?
  2. Which line is about coding?
  3. Which line is about software development?
  4. Listen again and identify one tech word and one study/work action.

Answer Key

  1. Artificial intelligence.
  2. 我写代码。
  3. 我喜欢软件开发。
  4. Any correct pair such as 代码 + 写 or 人工智能 + 学习.
