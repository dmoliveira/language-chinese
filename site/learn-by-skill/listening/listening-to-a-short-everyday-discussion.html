Level 3 listening

Listening to a Short Everyday Discussion

Listen to a short discussion and identify the main topic, support details, and response.

Objectives

  • understand the main point of a short discussion
  • identify one support detail and one response

Before you listen

  • listen first for the topic
  • then identify one detail that supports it
  • finally notice how the second speaker responds

Sample discussion

A: 这篇文章说学习中文的方法。
zhè piān wénzhāng shuō xuéxí zhōngwén de fāngfǎ.
This text talks about ways to study Chinese.
B: 我觉得这个方法不错，因为很清楚。
wǒ juéde zhège fāngfǎ búcuò, yīnwèi hěn qīngchu.
I think this method is not bad because it is very clear.

Practice

  1. What is the discussion about?
  2. What is the opinion?
  3. What is the reason?
  4. Listen again and identify the summary line and the response line.

Answer Key

  1. Ways to study Chinese.
  2. The method is not bad.
  3. Because it is clear.
  4. The first line is the summary line; the second is the response.
