Level 2 listening

Listening to Simple Opinions

Listen to short connected lines where a speaker gives an opinion and a reason.

Objectives

  • understand a short opinion statement
  • notice a simple supporting reason

Before you listen

  • Listen first for the opinion phrase.
  • Then notice one supporting detail or reason.
  • Finally ask yourself whether the speaker sounds positive, neutral, or uncertain.

Vocabulary focus

  • 觉得 — think / feel
  • 很好 — very good
  • 不错 — not bad
  • 因为 — because
  • 所以 — so / therefore

Sample listening lines

我觉得这个很好，因为很方便。
wǒ juéde zhège hěn hǎo, yīnwèi hěn fāngbiàn.
I think this is very good because it is convenient.
我觉得那个不错，所以我想试一试。
wǒ juéde nàge búcuò, suǒyǐ wǒ xiǎng shì yi shì.
I think that one is not bad, so I want to try it.

Practice

  1. Which phrase shows the speaker’s opinion?
  2. Which word introduces a reason?
  3. What does the speaker think is convenient?
  4. What does the second speaker want to try?

Answer Key

  1. 我觉得...
  2. 因为
  3. The thing being discussed in the first line.
  4. The option described as 不错.
