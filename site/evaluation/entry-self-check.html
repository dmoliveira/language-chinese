Entry Self-Check

A lightweight self-check to help learners choose a starting point.

Where you are in the beginner path

You have finished the first core lessons. Use this check to confirm whether you should keep reviewing or move into the guided study plan.

← Previous: Writing BasicsNext: 2-Week Study Plan →

Purpose

Use this self-check to decide whether you should start at Level 0 or review selected foundations first.

Instructions

Read each statement and answer honestly with yes, somewhat, or not yet.

Questions or Tasks

  1. I can read pinyin with basic tone marks.
  2. I know what 你好 means.
  3. I can say 我叫 ... with my own name.
  4. I can recognize at least one or two basic characters such as 我 or 你.
  5. I feel comfortable starting with absolute beginner content.

Scoring or Interpretation Guidance

  • Mostly not yet: start with Level 0 from the beginning.
  • Mostly somewhat: start with Level 0 and move slowly.
  • Mostly yes: you may still use Level 0 for review, but you can progress quickly.

Recommended Next Steps

  • Begin with Pinyin and Tone Basics
  • Then study Pronunciation, Tones, and Basic Self-Introduction
  • Follow with Greetings and Introductions
  • If you want a guided path, start Two-Week Absolute Beginner Starter
