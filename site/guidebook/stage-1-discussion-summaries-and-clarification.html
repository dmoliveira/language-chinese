Stage 1 — Discussion, Summaries, and Clarification

Learn to summarize short content, state opinions more clearly, and ask clarifying questions in everyday discussion.

Target outcomes

  • can summarize a short text or explanation
  • can state a supported opinion in several connected lines
  • can ask and answer clarification questions more naturally
  • can handle a short everyday discussion task

Unit sequence

  • Unit 1 — Discussion, Summaries, and Clarification

Review support

  • Summary and Discussion Core Set
  • Summarize and Respond Checkpoint

How to study this stage

  • practice understanding the main idea first
  • then identify supporting details
  • then add your own short response
  • finally practice clarification questions
