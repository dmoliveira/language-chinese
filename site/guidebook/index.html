Guidebook path

Handbook Structure

Follow a longer-form route through Parts, Stages, and Units instead of only browsing by skill.

Current handbook entry point

The project now has four major handbook parts outlined and an optional tech route for career-focused learners.

  • Part I — Foundations
  • Part II — Core Beginner
  • Part III — Everyday Expansion
  • Part IV — Independent Intermediate Use
  • Part V — Applied Tracks

How to use the handbook

  • Start with the guidebook if you want a book-like route.
  • Use Browse by Stage if you want a flatter overview across all levels.
  • Use skill pages if you want to browse by listening, reading, writing, or speaking.
  • Use references, decks, and evaluation pages as support tools around the handbook path.

Recommended order for new learners

  1. Start with Part I — Foundations.
  2. Complete Part II — Core Beginner.
  3. Move into Part III — Everyday Expansion.
  4. Use study plans and checkpoints at the end of each stage.
  5. Continue into Part IV when the earlier parts feel stable.

Current scope

The handbook structure is now live from Part I through the opening stage of Part IV, with an optional tech route available alongside it.

What this is best for

The guidebook is best for learners who want one coherent route over months or years, instead of using the site only as a library of separate pages.
