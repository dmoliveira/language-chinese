# Review System Specification

## Objective

Define the retention and review system required for a 2 to 4 year Chinese learning journey.

## Principle

Chinese learning requires cumulative review. New content should never fully replace old content; it should revisit and recycle it.

## Standard review loop

Every unit should include:

1. **same-day retrieval**
2. **2 to 3 day review**
3. **1 week review**
4. **unit-end integrated task**
5. **spiral review in the next unit or stage**

## Review layers

### Lesson review

- flashcards
- short answer checks
- self-reading or self-speaking repetition

### Unit review

- mixed-skill recap
- small integrated task
- common error checklist

### Stage review

- broader cumulative review
- milestone checklist
- reflection on weak points and next steps

### Long-range review

- stage-end cumulative review
- level milestone review
- optional later monthly or quarterly review bundles

## Retrieval rule

Review should not only be re-reading. It should include retrieval from memory, such as:

- recalling meaning from hanzi or pinyin
- saying a sentence pattern from memory
- filling a missing word in a sentence
- summarizing a short text after reading it

## Cross-skill recycling rule

Important content should return in multiple formats:

- hear it
- read it
- say it
- write it
- review it in a deck

## Required review artifacts per unit

- at least one flashcard/deck tie-in
- at least one short review task
- at least one cumulative checkpoint prompt

## Learner-facing guidance

The site should explain that review is not failure; review is a normal part of the path.

## Future-friendly extensions

- printable review sheets
- spaced-review exports
- optional monthly review bundles
- optional module review dashboards
