# Contribution and Governance Specification

## Objective

Prepare the project for safe public collaboration with clear expectations for code, content, media, and data contributions.

## Minimum contribution rule

- contributors may only submit work they authored or work they can legally contribute under compatible terms
- all pull requests should identify whether the submission contains original work, adapted work, or link-only references

## Inbound licensing rule

- contributed code is accepted under the repository code license
- contributed original educational content is accepted under the repository content license
- contributed data or media must declare a compatible license before merge

## Review gates

- source and attribution check
- accessibility check
- lesson metadata check when content is involved
- scope check to avoid oversized changes in one submission

## Public professionalism rule

- explanations should be respectful, beginner-friendly, and concise
- technical content should remain understandable to non-specialists where possible
- claims about AI evaluation must remain modest and clearly qualified
