# Assessment Model Specification

## Principles

- assessment should support learning, not punish learners
- static-first delivery means manual and rubric-based methods come before heavy automation
- automated scoring must be presented as guidance, not authoritative judgment

## Assessment layers

### Placement

- self-check questionnaire
- short diagnostic tasks by skill
- recommended entry point

### Lesson checks

- 3 to 5 short tasks
- immediate answers for objective items
- rubrics for open responses

### Unit exit checks

- one integrated task per unit
- simple completion criteria

### Stage and level milestone reviews

- cross-skill review after each stage or level band
- can-do statements
- learner reflection and gap identification

## Skill-specific evaluation

### Listening

- multiple choice or short answer comprehension
- transcript-supported self-check

### Reading

- gist questions
- detail questions
- vocabulary-in-context checks

### Writing

- guided responses
- sentence transformation
- short paragraph tasks
- rubric for clarity, grammar, vocabulary use, and task completion

### Speaking

- shadowing checklists
- prompt response tasks
- self-recording tasks
- heuristic browser feedback where available

## AI-assisted feedback policy

- speaking feedback may use browser or open-source speech-to-text tools
- pronunciation or fluency scores must be labeled as approximate practice feedback
- writing evaluation may start with guided checklists before any automated review features

## Level model

- Level 0: foundations
- Level 1: beginner
- Level 2: early intermediate
- Level 3: functional intermediate
- Technical track overlay across Levels 1 to 3

## Evidence requirements

- answer keys for objective tasks
- rubrics for open tasks
- visible progression criteria for study plans
