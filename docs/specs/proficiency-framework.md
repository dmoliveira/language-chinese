# Proficiency Framework Specification

## Objective

Define a measurable progression model so the project can grow into a credible multi-year Chinese learning guidebook.

## Recommended model

Use a hybrid model:

- **Canonical learner-facing progression:** CEFR / ACTFL-style functional ability
- **Secondary checkpoints:** HSK 3.0 vocabulary and character targets where useful

This avoids over-centering exam preparation while still keeping public benchmarks available.

## Level definitions

### Level 0 — Foundations / Pre-A1

Focus:

- pinyin and tone awareness
- survival phrases
- first sentence patterns
- first high-frequency characters and words

Suggested outcome range:

- 100 to 150 active words
- 50 to 80 common characters recognized
- can greet, introduce self, recognize simple chunks, and read tiny supported texts

### Level 1 — Beginner / A1-ish

Focus:

- daily life language
- short guided listening and reading
- short sentence-level writing and speaking
- common topics such as routine, time, food, family, study, and work

Suggested outcome range:

- 400 to 600 active words
- 150 to 250 common characters recognized
- can describe simple routines, ask and answer basic personal questions, and understand short controlled texts

### Level 2 — Early Intermediate / A2-ish

Focus:

- connected language
- short explanations and summaries
- broader topic range
- stronger reading/listening tolerance

Suggested outcome range:

- 1000 to 1500 active words
- 400 to 600 common characters recognized
- can understand and produce short connected paragraphs on familiar topics

### Level 3 — Functional Intermediate / B1-ish

Focus:

- practical independent use
- discussion, explanation, comparison, and clarification
- wider reading and more independent speaking/writing

Suggested outcome range:

- 2000+ active words
- 800+ common characters recognized
- can function across familiar study/work/life situations with moderate support

## Technical overlay rule

Technical Chinese should begin after the learner has a stable general beginner base.

Recommended point of entry:

- visible in Level 1
- meaningfully expanded in Levels 2 and 3

## What each level must define

For each level, publish:

- can-do statements
- grammar scope
- vocabulary scope
- character scope
- required unit count
- review expectations
- milestone check type

## Can-do statement style

Good can-do statements are practical and observable.

Examples:

- I can introduce myself in 2 to 4 simple sentences.
- I can understand a short daily routine description.
- I can read a short beginner paragraph with support.
- I can ask and answer simple time and schedule questions.

## Assessment role

The proficiency framework is not only descriptive; it should drive:

- study plans
- stage gates
- lesson sequencing
- milestone check design

## Public communication rule

The project should not claim official certification equivalence. It can say that content is *compatible with* or *aligned to* broad public benchmarks, but not that it grants formal exam standing.

The public site should use the CEFR / ACTFL-style progression as the main explanatory frame and mention HSK only as a reference checkpoint system.
