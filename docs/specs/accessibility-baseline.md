# Accessibility Baseline Specification

## Accessibility goal

Meet a strong practical baseline aligned with WCAG 2.1 AA for public educational content.

## Core rules

1. Full keyboard navigation.
2. Sufficient color contrast.
3. Responsive layout for mobile and desktop.
4. No essential information hidden by color alone.
5. Semantic headings and clear page structure.
6. Interactive elements must expose visible focus and clear labels.

## Audio and media rules

- every audio lesson must provide a transcript
- every video must provide captions or equivalent text support
- controls must be usable without precise pointer interaction

## Language presentation rules

- English explanations should be plain and concise
- pinyin should be available where it materially helps beginners
- hanzi, pinyin, and English text should remain visually distinguishable
- avoid image-based text for lesson content
- multilingual pages should use correct language metadata where practical
- mixed hanzi, pinyin, and English sequences should preserve a clear reading order for assistive technologies
- pronunciation aids such as ruby or similar markup should be used consistently when introduced

## Cognitive accessibility rules

- short sections
- predictable lesson templates
- visible difficulty labels
- estimated study time on each lesson
- clear next-step links

## Professional quality rules

- consistent terminology
- consistent typographic treatment for Chinese and English text
- avoid unnecessary visual clutter
- maintain print-friendly or low-distraction reading options where practical

## Review checklist

- transcript present when media exists
- headings in logical order
- links descriptive
- interactive exercises usable by keyboard
- interactive forms and controls clearly labeled
- error or answer feedback understandable in text form
- answer feedback understandable without audio
