# Roadmap Specification

## Delivery strategy

Build the project in public, in small publishable slices, starting with planning and moving toward a static-first educational MVP.

## Milestone 1: planning foundation

- product specification
- sourcing and licensing specification
- privacy and data handling specification
- contribution and governance specification
- information architecture
- content model
- content workflow
- assessment model
- accessibility baseline
- roadmap

### Exit criteria

- scope is documented
- licensing posture is clear
- privacy posture is clear
- module architecture is defined
- MVP boundary is explicit

## Milestone 2: curriculum skeleton

- define learner levels
- define first study plans
- define lesson template
- define first module inventory

### Exit criteria

- all four core skills have initial lesson targets
- flashcards and evaluation hooks are mapped
- tech-track overlay topics are defined
- one canonical lesson template and source manifest example exist

## Milestone 3: GitHub Pages MVP

- choose static site approach
- publish homepage and navigation
- publish starter lessons
- add quizzes and answer keys
- add initial flashcard support

### Exit criteria

- public site is navigable
- beginner path exists
- every module has at least one live starter page

## Milestone 4: evaluation and applied practice

- add writing evaluation workflows
- add speaking practice workflows
- prototype browser-side AI-assisted feedback
- expand reading and listening packs

### Exit criteria

- learners can complete guided practice in all four skills
- automated feedback is clearly labeled as non-authoritative

## Milestone 5: growth and contributor maturity

- expanded contribution standards
- source manifests and validation helpers
- broader lesson library
- stronger references and study plans

### Exit criteria

- contributors can add lessons consistently
- public quality bar is documented and repeatable

## MVP definition

The first public MVP should include:

- one clear beginner onboarding path
- one starter module each for listening, reading, writing, and speaking
- flashcards connected to starter lessons
- at least two study plans
- reference pages for pronunciation, pinyin, and core grammar
- basic evaluation through quizzes, answer keys, and rubrics

## Major risks

- scope sprawl
- unclear licensing of third-party materials
- overpromising AI evaluation quality
- inaccessible media-heavy content

## Mitigations

- keep first release small
- use strict sourcing manifests
- label automation honestly
- require transcripts and structured templates
