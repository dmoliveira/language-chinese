# Reference Roadmap Specification

## Objective

Define the reusable explanation system that supports the handbook over multiple years.

## Role of references

References should reduce lesson repetition by holding canonical explanations that many lessons can point to.

## Reference categories

### Pronunciation

- pinyin and tones
- pronunciation guide
- later difficult sound contrasts

### Sentence patterns and grammar

- core sentence patterns
- question forms
- negation
- time and date expressions
- quantities and measure words
- connectors
- comparison
- aspect basics

### Vocabulary systems

- starter vocabulary
- routine verbs
- family words
- study/work vocabulary
- high-frequency function words

### Character learning

- character recognition strategy
- component/radical awareness
- high-frequency character clusters

### Learning method

- how to use decks
- how to review effectively
- how to shadow and self-record
- how to study reading and writing separately

## Priority order

### Current/near-term

- pronunciation and pinyin
- core sentence patterns
- starter vocabulary

### Next

- question forms
- negation
- time/date/quantity
- routine verbs

### Later

- comparison
- connectors
- aspect basics
- character learning strategy

## Reference design rule

Every reference should include:

- what it is for
- key concepts
- examples
- common mistakes
- linked lessons
- source/license notes

## Publication rule

No major lesson cluster should depend on explanations that exist only inside one lesson page. If a concept repeats, promote it into a reference page.
