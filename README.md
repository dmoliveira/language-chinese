# Language Chinese

Open Chinese-learning materials for English speakers, with strong support for learners interested in technology, computer science, software, and AI/ML contexts.

## Project goals

- teach listening, reading, writing, and speaking in a clear progression
- publish reusable open educational content
- provide flashcards, quizzes, study plans, references, and evaluation pages
- stay accessible, professional, and GitHub Pages-friendly
- support general learners while offering a technical-language overlay

## Current status

This repository currently includes:

- MVP planning and specifications under `docs/`
- starter Level 0 curriculum content under `content/`
- a static site scaffold under `site/`
- GitHub Pages deployment workflow under `.github/workflows/`

## Repository structure

- `content/` — lessons, references, decks, study plans, evaluation content, templates
- `docs/` — product, curriculum, accessibility, roadmap, sourcing, and governance specs
- `scripts/` — helper scripts and validation utilities
- `site/` — public GitHub Pages site files
